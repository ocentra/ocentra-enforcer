=== compile-reject fixture (manual, proved at review time -- see acceptance
criterion "the private field makes a bare `String` populating a `Sha256`
field a compile error") ===
The following does NOT compile against crates/enforcer-domain/src/hashes.rs:

    struct Holder {
        digest: enforcer_domain::hashes::Sha256,
    }
    fn bad(raw: String) -> Holder {
        Holder { digest: raw } // expected `Sha256`, found `String`
    }

Fails with E0308 (mismatched types): Sha256(String) has a private inner
field and no public tuple-index/constructor; there is no `From<String> for
Sha256` / `Into<Sha256> for String` impl (only the reverse, fallible
`TryFrom<String>` used by `parse`/`FromStr`), so a bare `String` never
satisfies a `Sha256`-typed field or parameter.
