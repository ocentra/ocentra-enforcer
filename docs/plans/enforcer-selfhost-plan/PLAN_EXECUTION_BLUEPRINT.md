## Parallel-execution model

### Frontier of disjoint-owns workpacks

At any moment the **frontier** = packs whose `deps:` are all DONE and whose `owns:` glob sets are pairwise disjoint from each other and from every claimed lane. The frontier is computed from `WORKPACK_INDEX.md` (deps + owns columns). Multiple agents draw from the frontier simultaneously because disjoint `owns:` means no write collides. `NEXT_ACTIONS.md` publishes the current frontier.

### Hub lanes

The **hub** owns sequencing. It assigns each agent a **lane** = one workpack's `owns:` set. A lane is exclusive: while claimed, no other agent may write inside it. The hub keeps as many lanes open as the frontier allows and refills a lane as soon as a pack closes out and unblocks dependents.

### Claim / guard / closeout (per lane)

1. **Claim.** Agent selects one frontier pack, records the claim (pack id + `owns:` set) with the hub. If the `owns:` set intersects a live lane, the claim is refused.
2. **Guard.** A guard is set over the claimed `owns:` set. Any write outside the guarded set — or by another agent into it — is a violation (mirrors the C-track PreToolUse deny-hook: the plan enforces its own lanes mechanically).
3. **Do the work + prove.** Implement the Requirement Checklist; run the named tests at the required proof tier (see `TEST_PROOF_EXPECTATIONS.md`).
4. **Closeout.** Only with green proof: update the pack's proof rows and flip its `WORKPACK_INDEX.md` row to DONE, release the guard, release the lane. The hub recomputes the frontier and refills.

### Intent-queue for overlap

When a pack legitimately needs a change inside **another** pack's `owns:` set (a genuine cross-cut, not scope creep), the agent does **not** edit across the boundary. It files an **intent** on the owning lane's queue: `{ target owns-path, requested change, requesting pack }`. The owning agent (or the hub, if the lane is idle) services the intent inside its own guarded lane. This keeps every write attributable to exactly one lane and preserves disjointness as an invariant, not a hope.

### Invariants the hub maintains

- Disjoint-owns across all live lanes at all times.
- No lane closes out without green proof at its required tier.
- Every cross-lane change flows through the intent-queue, never a direct edit.
- A pack whose deps regress (a dep's proof goes red) is pulled back off the frontier.
