## How to read this index

- **Status**: `TODO` (not started) | `CLAIMED` (a lane holds it) | `IN-PROGRESS` | `PROOF` (code done, proof row not yet GREEN) | `DONE` (proof row GREEN + closed out). All rows start `TODO`.
- **owns disjoint?**: `Y` = this workpack's `owns:` globs are disjoint from every *concurrently-runnable* sibling (safe to claim in parallel). `Y*` = shares a file with a named sibling **by design** — must sequence or coordinate on that file (see the note). Two workpacks with no dep edge between them MUST have disjoint owns (PLAN-PARALLEL-SAFETY, enforced by b02).
- **tier**: the workpack's declared tier (proof-tier vocabulary; T-tier of the rule noted where scored/advisory). See [TEST_PROOF_EXPECTATIONS](./TEST_PROOF_EXPECTATIONS.md) for what each means.
- **parallel-safe with**: the frontier this workpack may run alongside once its deps are satisfied.
- Recommended global sequence (blueprint): **a01 (Rust toolchain) -> arc-01/arc-02 (workspace core + domain) -> rest of the arc crate swarm (incl. arc-25 `enforcer-events`) -> A domain packs (a02..a09) -> D01 -> feature packs (C/D/E/F/G/H) in parallel -> B last -> a10**. See [PLAN_EXECUTION_BLUEPRINT](./PLAN_EXECUTION_BLUEPRINT.md). (Track A is now a RUST Cargo workspace; see [RUST_ARCHITECTURE](./RUST_ARCHITECTURE.md).)

## Track A - Eat own dog food: RUST Cargo workspace + brand domains (newtypes) + real self-enforcement

Track A is re-cast to **Rust** (see [RUST_ARCHITECTURE](./RUST_ARCHITECTURE.md)). The 50-file `.mjs -> TS` conversion swarm is REMOVED and replaced by **`arc-01`..`arc-25`** — cohesive, dependency-ordered CRATE-BUILD workpacks (one per crate/subsystem, not file-1:1) that stand up the Cargo workspace. The `a01`..`a10` domain/self-enforcement packs are KEPT but are now Rust: brands -> `enforcer-domain` newtypes; toolchain -> Cargo + clippy/rustfmt/deny/audit + `rust-toolchain.toml`; fingerprint -> hash the built artifacts; self-enforcement -> the enforcer's own Rust rules on its own crates.

### A.0 Workspace + crate build swarm (arc-01 .. arc-25) — Cargo-workspace crates, dependency-ordered

`arc-01` (`enforcer-core`) is the first member crate every other crate depends on; `a01` owns the workspace root (`Cargo.toml`/`rust-toolchain.toml`) and precedes it. `arc-02` (`enforcer-domain`, the single-source schema of branded newtypes) is the P0 keystone the whole engine is typed against. **25 arc crates** stand up the workspace, including the new `arc-25` (`enforcer-events`, the lean in-process typed event spine consumed ONLY by scan/coordination/proof — see [RUST_ARCHITECTURE](./RUST_ARCHITECTURE.md)). **owns-narrowing:** an arc pack that HOSTS feature modules owns only its crate SKELETON (`Cargo.toml`, `src/lib.rs`, module registration, and named baseline files) — it does NOT wholesale-claim `src/rules/**`, `src/adapters/**`, or `src/hooks/**`; those files belong to the C/D/E/F/G/H feature packs that add them. Skeleton owns and feature owns are therefore disjoint by construction; parallel-safety within a wave is determined by the dep edges below.
